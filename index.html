How I Build

The thinking behind each project, in plain terms.

AI Code Debugger & Explainer
Problem
Error messages are hard to read for beginners, so they lose time guessing what went wrong.
Approach
Send the code to an LLM, ask it to find likely issues, and return the explanation in simple language.
Technology
Python, FastAPI, LLM APIs, React.
Result
A working tool that turns code errors into plain-English explanations. No performance metrics have been measured yet.
FraudGuard AI
Problem
Everyday users find it hard to tell whether a message, link or activity is a scam.
Approach
Analyze suspicious input with AI and present the warning signs in a clear, readable way.
Technology
Python, FastAPI, Generative AI, SQLite.
Result
A prototype that flags potential fraud indicators for the user to review. Accuracy has not been formally benchmarked.
KidsAI Studio
Problem
Creating safe, educational content for children takes a lot of time and creative effort.
Approach
Use generative AI to draft stories, animations and short-form ideas, presented in a friendly interface.
Technology
React, Vite, Tailwind CSS, Generative AI.
Result
A prototype that generates educational content ideas. Not yet tested with real users.
AI Cyber Threat Intelligence Platform
Problem
Threat data is scattered and technical, which makes it hard to see what needs attention first.
Approach
Design a platform that gathers threat information and uses AI to summarize what matters.
Technology
Python, AI Automation, REST APIs.
Result
Currently a platform concept and design. It is not a finished product.
